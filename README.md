# Puma

A modern Puma-inspired sports and lifestyle website focused on performance, speed, innovation, and bold visual design.

## Overview

This project is a front-end website inspired by Puma's visual identity and sportswear culture. It combines athletic aesthetics with a modern web experience to showcase Puma as a performance-driven sports and lifestyle brand.

The website focuses on:

* Modern and responsive UI design
* Sports and lifestyle branding
* Bold visual presentation
* Performance-oriented design
* Interactive media and animations
* Clean and immersive user experience

## Features

* Puma-inspired landing page
* Modern sports-focused design
* Responsive layout
* Video-based visual elements
* Image and multimedia assets
* Brand-focused sections
* Clean and minimal navigation
* Interactive visual experience

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Video and image assets
* Netlify for deployment
